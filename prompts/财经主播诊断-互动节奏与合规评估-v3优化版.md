# 财经主播诊断 · 互动节奏与合规评估（v3优化版）

## 用前必读

### 适用场景
拿到一位或多位财经主播逐字稿后，用这套提示词生成诊断报告。

适用对象：
- 基金顾问主播
- 财经投教主播
- 行业解读主播
- 复盘类主播
- 课程转化型主播

### 两种使用模式
**完整版**：深度复盘，适合新主播首次评估或月度大复盘。跑完所有模块。
**快速版**：日常检查，适合每周例行。只跑模块0、2、3、5。

### 核心原则
- 每个判断后面都要跟证据。没有原文就别下判断。
- 合规只看实质表达。不搞关键词洁癖。
- 出现"涨、跌、买、卖"不等于违规。要看有没有具体对象、操作动作、确定结果。
- 优化建议必须能落地。不能把主播改成另一个人。
- 不要建议"扣1扣2"这种廉价互动。可以建议有质感的评论区文字互动。

### 报告写作风格
- 用短句。一句话超过25字就拆。
- 直接说"行"还是"不行"。
- 禁止出现：`首先、其次、最后`、`综上所述`、`值得注意的是`、`在某种程度上`、`从某个角度来看`。
- 禁止用破折号做解释。
- 别写"希望这份报告对您有帮助"。
- 像内部运营复盘。不像公文。不像AI总结。

## 模块0：先定人设（必填）

用一句话说清楚这人靠什么吃饭。

> 人设一句话：[例如：稳健投教型基金顾问，靠产业逻辑和风险提醒建立信任，不靠喊单。]

后面所有建议都要问一句：这会不会毁他人设？

## 模块1：语速与内容负荷

### 1-A 字数与语速
统计：
- 逐字稿总字数，不含空格。
- 直播时长。
- 估算语速，字/分钟。

口播语速区间：
| 区间 | 字/分钟 | 听感 | 财经直播含义 |
|---|---:|---|---|
| 慢速 / 舒缓区 | 150-200 | 留白多，适合消化 | 适合风险教育、长期陪伴 |
| 中速 / 舒适区 | 200-240 | 自然，不急 | 适合基金投教、日常复盘 |
| 快速 / 高能区 | 240-280 | 明快，信息密 | 需要互动缓冲 |
| 超快 / 极限区 | 280以上 | 信息压迫强 | 必须切小段，不然听累 |

### 1-B 语速判断
输出：
- 语速区间
- 听感
- 跟人设是否匹配
- 语速和互动密度是否匹配

不要只说快慢。要说"快在哪里""观众会不会累""有没有互动缓冲"。

## 模块2：合规初筛

### 判断标准
看三件事：
1. 有没有具体对象。
2. 有没有操作动作。
3. 有没有确定结果。

三者凑齐，优先按高风险处理。

### 2-A 必查8类风险
1. **具体投资建议**：买、卖、持有、加仓、减仓、低吸、抄底、逃顶、止盈、止损、做T、跟着买。
2. **具体证券或产品引导**：个股、基金、板块、指数、行业主题，被配上"现在能看、可以布局、后面有机会"等行动暗示。
3. **确定性预测**：明天、下周、月底、某点位、某价位，加上必然方向。比如"肯定突破""一定回调""必上XXX点"。
4. **收益承诺或风险淡化**：稳赚、不亏、保本、低风险高收益、躺赚、翻倍、不会吃面。
5. **内幕、主力、机构叙事**：内幕消息、独家爆料、主力进场、聪明钱在买、国家队拉盘。没有可靠来源，一律提风险。
6. **营销误导**：课程、社群、服务被暗示能提高收益、规避亏损、拿到代码、获得买卖点。
7. **导流或隐蔽建联**：加微信、私信、进群、看主页、扣字、老地方见、后台发资料。
8. **身份与资质风险**：自称分析师、理财师、基金经理、首席、专家。没有机构、姓名、执业编号的，提风险。

### 2-B 不要误伤这些
- 事实复盘："今天涨了""今天跌了"。
- 风险教育："不要追涨杀跌""控制仓位"。
- 投教表达："分散配置""长期持有要看风险承受能力"。
- 中性宏观/行业分析。
- 已经明确风险提示，且没有具体操作指令的观点。

### 2-C 合规风险表
| 风险点 | 原话 | 等级 | 命中规则 | 用户可能怎么理解 | 怎么改，语气不能变 |
|---|---|---|---|---|---|

等级：
- **红线**：必须删或重写。
- **高风险灰区**：必须改。
- **中风险灰区**：建议改。
- **低风险观察**：可保留，但建议更稳。

改写原则：
- 把"买卖动作"改成"观察维度"。
- 把"确定结果"改成"条件判断"。
- 把"收益暗示"改成"风险收益特征"。
- 把"导流动作"改成平台内合规承接。
- 风险提示不要只放结尾。关键观点前也要有。

## 模块3：关键互动指标

逐场统计：
| 指标 | 数值 |
|---|---|
| 首次有效互动时间 | |
| 前15分钟互动次数 | |
| 前15分钟最长干货段 | |
| 全场最长干货段 | |
| 互动设计类型 | |
| 合规风险最高点 | |
| 用户参与感 | |

定义：
- **有效互动**：提问、调查、点名、回应弹幕、让用户做选择、让用户复述标准。
- **无效互动**：机械要点赞、泛泛欢迎、没有承接的口号。
- **最长干货段**：没有互动锚点打断的连续内容输出。

判断线：
- 首次有效互动超过3分钟，新粉留存压力大。
- 干货段超过4分钟无互动，注意力容易散。
- 只有点赞号召，不算互动设计丰富。
- 高频互动如果全是"扣1"，也不算高质量。

## 模块4：表达基因分析

别凭感觉，拿原话对。以下6项，每项都要有原文证据。

### 4-1 语气情绪
- 啥样：打鸡血 / 冷静 / 幽默 / 沉稳 / 家常
- 证据：截一段
- 跟人设搭吗：情绪稳不稳？有没有突然掉线或太过的时刻？

### 4-2 用词与可懂度
- 术语多不多：高 / 中 / 低。他解释吗？
- 会不会说人话：强 / 中 / 弱。比喻、故事用得多吗？
- 证据：术语原句一句，白话版一句。
- 散户听着累不累？

### 4-3 内容模式
- 啥模式：每天复盘流水线 / 逮一个主题深挖 / 跟着热点跑 / 固定栏目加零碎
- 证据：描述这场咋播的
- 观众能养成习惯吗？他撑得住天天这么讲吗？

### 4-4 视角与标签
- 从哪切入：宏观 / 行业 / 个股 / 技术图 / 资金面 / 啥都掺点
- 证据：截一段
- 这是他的标签吗？跟别人不一样在哪？

### 4-5 敢下判断吗
- 啥风格：明确说涨跌 / 列几种可能让你选 / 只给框架 / 说了等于没说
- 证据：截一段观点
- 下判断的时候带风险提示了吗？还是光顾着爽？

### 4-6 怎么叫观众
- 叫啥：家人们 / 老铁 / 兄弟们 / 各位投资者 / 朋友们 / 咱们散户
- 证据：列3-5处
- 这称呼是拉近距离了，还是显得更专业了？

## 模块5：六维评分 + 优先改进项

### 5-A 六维评分

| 维度 | 分 | 原文证据 | 卡在哪 | 怎么改（不能毁人设） |
|---|---|---|---|---|
| 内容专业度 | | | | |
| 合规安全 | | | | |
| 结构节奏 | | | | |
| 表达呈现 | | | | |
| 互动承接 | | | | |
| 转化效率 | | | | |

打分参照（别拍脑袋）：
- **专业度**：10=逻辑闭环，引用有出处。6=大体通，有小跳步。3=没支撑，纯感觉。
- **合规**：10=风险提示前置，观点克制，不给具体操作。6=有灰区诱导或确定性语气，但能改。3=出现明确交易建议、收益承诺、导流成交、虚假身份、内幕暗示。
- **结构节奏**：10=开场勾人，主线清楚，转场顺，结尾有钩子。6=还行但有小毛病。3=散装，听不下去。
- **表达**：10=语速舒服，没口癖，情绪对。6=偶尔卡。3=口癖多到烦。
- **互动**：10=接评论自然，互动钩子巧。6=有互动但硬。3=自言自语。
- **转化**：10=转化顺滑，压迫感低，数据好。6=有动作但时机怪。3=要么没转化，要么逼太紧。

### 5-B 优先改进项（3-5条）

排序：① 踩红线的 ② 真伤体验的 ③ 挡着转化的

每条格式：
- **问题**：写清楚
- **现在咋干的**：原话
- **跟人设冲突吗**：改完会不会别扭
- **团队推得动吗**：主播认不认，运营干得了吗
- **改成这样**：给句能直接用的话

## 模块6：可借鉴动作

针对互动弱或合规弱的主播，给具体动作。

每条必须这样写：
- **动作**：具体改什么。
- **当前问题**：引用原文。
- **参考哪里**：写结构，不照搬话术。
- **合规改法**：把可能踩线的话术改成安全表达。
- **优化方案**：给一句主播能直接说的话。
- **为什么有效**：说清因果。
- **是否毁人设**：明确不毁，或说明怎么保人设。

示例格式：
> **动作**：把"行业还能不能玩"改成"用户状态分层"。
>
> **当前问题**：原文是"商业航天还能玩不能玩"，这是行业问题，用户不知道自己该怎么处理基金。
>
> **参考哪里**：参考"先让用户暴露状态，再进入教学"的结构。
>
> **合规改法**：不问"买没买、加没加"，改问"持有、观望、空仓"。
>
> **优化方案**："你现在属于哪类，持有相关主题基金、准备观察、还是完全没配置？评论区写状态，我按三类讲。"
>
> **为什么有效**：主播能知道用户结构，后面建议更像顾问服务，不像单向讲课。
>
> **是否毁人设**：不毁。研究型主播只是多了服务感。

## 模块7：逐字稿优化片段

从原稿里截一段3-5分钟的内容，做两件事：点出优缺点，按人设重写一版——合规、抓人、口吻不变。

### 7-1 选定片段
- 时间区间：几分几秒 到 几分几秒
- 内容概括：这段在讲什么

### 7-2 原片段
粘贴原话，一字不改。

### 7-3 优点
- 优点1 —— 证据：原话片段
- 优点2 —— 证据：原话片段

### 7-4 缺点
- 缺点1 —— 证据：原话片段
- 缺点2 —— 证据：原话片段

### 7-5 结构问题
- 这段逻辑推进顺不顺？有没有跳步或重复？
- 转场硬不硬？

### 7-6 优化后版本（用主播口吻）
保持原人设、合规、更抓人、字数大致相当。

### 7-7 改动说明
- 改了哪几个地方
- 为什么这么改（人设/合规/留人/逻辑）
