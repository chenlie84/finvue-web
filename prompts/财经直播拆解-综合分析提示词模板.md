# 财经直播拆解 · 综合分析提示词模板

> 基于"财经葛先生直播拆解"和"史宇辰直播分析报告"两套框架整合形成
> 适用场景：投顾主播直播诊断、竞品分析、主播培训

---

## 一、核心分析框架概述

### 六层递进拆解模型

```
骨架层（结构）→ 血肉层（内容）→ 价值层（策略）→ 表达层（话术）→ 灵魂层（风格）→ 迁移层（模板）
（怎么搭的）    （讲了什么）      （给什么价值）    （怎么说的）      （为什么有效）    （我怎么用）
```

### 核心分析方法

| 方法 | 说明 | 应用场景 |
|------|------|---------|
| 树干隐喻法 | 用"树干-枝杈-叶片"比喻信息架构 | 结构分析 |
| 四类话术矩阵 | 按功能分类话术（互动/情绪/风险/钩子） | 话术分析 |
| 三标签提炼法 | 把风格压缩为三个可模仿的行为标签 | 风格分析 |
| 板块扫描模板 | 发现对同类内容的统一分析模板 | 策略分析 |
| 全景鸟瞰表 | 用一张表展示核心指标与行业标准对比 | 快速诊断 |
| 合规边界分析 | 按投顾口径分析每句话的风险 | 合规检查 |

### 第一层：骨架层 · 结构拆解

**分析方法：**
1. **树干隐喻法**：用一个比喻/模型概括整场结构（树干式/洋葱式/三幕剧式...）
2. **时间分配表**：统计各阶段时长占比，分析节奏合理性
3. **信息流向分析**：分析"发散-收束"节奏，发现回拉机制
4. **结论位置分析**：判断结论是先行还是后置

**输出格式：**
- 整体结构模型（用比喻描述）
- 核心锚点：贯穿全场的主题是什么？
- 时间分配表（按阶段统计）
- 发散-收束节奏分析
- 结论位置判断（先行/后置）及策略说明

---

### 第二层：血肉层 · 内容拆解（逐段拆解）

**核心要求：对每段原话做拆解分析，格式 = 原话 + 分析**

**分析方法：**
1. **逐段拆解**：按时间轴逐段拆解，每段包含：时间段 + 内容标签 + 原话引用 + 拆解分析
2. **话题清单表**：列出所有核心话题、时长、论证结构、核心结论
3. **论证结构分析**：拆解"结论先行→论据展开→操作建议"的结构
4. **逻辑链条分析**：梳理整场内容的逻辑路径
5. **论证手法识别**：识别使用了哪些论证手法（数据/案例/类比/权威引用）

**输出格式：**

#### 2.1 逐段拆解表（核心输出）

按时间轴逐段拆解，每段都要包含"原话+分析"：

| 时间段 | 内容标签 | 原话引用 | 拆解分析 |
|--------|---------|---------|---------|
| 00:00-00:XX | 干货/互动/情绪 | "原文引用" | 分析这段话的目的、手法、效果、问题 |

**内容标签类型：**
- `干货`：知识输出、理念讲解、方法传授
- `互动`：提问引导、状态调查、投票互动
- `情绪`：共情表达、情绪调动、心态建设
- `风险`：风险提示、合规表达
- `钩子`：关注引导、预约引导、预告内容

**拆解分析维度：**
- 这段话的目的是什么？（建立认知差/输出理念/制造共鸣/引导互动/提示风险）
- 使用了什么手法？（比喻/案例/数据/类比/权威引用/反向提问）
- 效果如何？（有效/一般/有问题）——给出判断
- 有什么问题或改进空间？（如有问题则指出）

#### 2.2 话题清单表
- 话题清单表（话题|时长|论证结构|核心结论）

#### 2.3 论证结构分析
- 论证结构分析（每个核心话题的论证路径）

#### 2.4 整场逻辑链条
- 整场逻辑链条（从开场到收尾的逻辑路径，用箭头连接）

#### 2.5 论证手法清单
- 论证手法清单及出现频次

#### 2.6 信息密度评估
- 信息密度评估（每分钟关键信息点数量）

---

### 逐段拆解输出示例（供参考）

```
【示例1：开场干货段】
时间段：00:00-00:25
内容标签：干货
原话："书接上回，上回咱们说为什么我们要学习一些机构或者量化的思维，然后分析一下自己的优劣势。"
拆解分析：
- 目的：开场直接进入主题，建立"机构思维 vs 散户思维"的认知差
- 手法：承接式开场（"书接上回"），暗示连续追看的价值
- 效果判断：有效，效率高；但缺少热场和情绪价值，新粉可能划走
- 改进建议：开场前先讲今日盘面爆点，再过渡到理念

【示例2：理念输出段】
时间段：00:25-01:30
内容标签：干货 + 互动
原话："投资是一个做未来的事，你需要提前布局……有没有这样的一个感受？如果你们也做过投资，你会感觉到是一个钓鱼，放长线钓大鱼。"
拆解分析：
- 目的：输出"长期投资"理念，降低用户焦虑
- 手法：比喻手法（"投资是钓鱼"），通俗易懂
- 效果判断：比喻有效，但互动"有没有感受"是弱互动，用户难回应
- 改进建议：改为封闭式互动："觉得投资像钓鱼的打1，不像的打2"

【示例3：批评行为段】
时间段：01:30-03:00
内容标签：干货（风险提示）
原话："我不太明白为什么散户总喜欢每天追热点、看行业、看概念……你们在看什么？是在看图形吗？看均线吗？是不是太累了？"
拆解分析：
- 目的：批评用户行为，制造认知冲突
- 手法：反向提问，连续追问
- 效果判断：有问题——站在"高处"批评用户，容易产生抵触情绪
- 改进建议：改为共情式引导："我知道大家每天看盘面很累，因为我也经历过"
```

### 第三层：价值层 · 策略拆解

**分析方法：**
1. **板块扫描模板**：发现博主对同类内容使用的统一模板（定性→定因→定策）
2. **可执行建议表**：列出给观众的具体建议、适用条件、风险提示
3. **方法论输出分析**：判断是否有方法论输出，不只是理念

**输出格式：**
- 模板化发现：博主对同类内容是否使用统一模板？模板结构是什么？
- 可执行建议表（建议内容|适用条件|风险提示）
- 方法论评估：是否有具体方法，还是只有理念？

---

### 第四层：表达层 · 话术拆解

**分析方法：**
1. **四类话术矩阵**：按功能分类全场话术
   - 互动引导话术（让观众参与）
   - 情绪话术（调动情感）
   - 风险把控话术（合规保护）
   - 下钩子话术（留存转化）
2. **互动设计分析**：分析互动类型、出现频次、参与门槛
3. **话术节奏分析**：分析互动话术的插入频率和分布位置

**输出格式：**
- 话术分类矩阵（类型|代表话术|功能分析|出现频次）
- 高光话术（最值得学习的3-5句）：原文 → 拆解有效原因 → 可迁移场景
- 互动设计评估（互动类型|出现次数|参与门槛|效果判断）
- 话术节奏分析（互动插入频率|钩子分布位置）

---

### 第五层：灵魂层 · 风格拆解

**分析方法：**
1. **三标签定义法**：把个人风格压缩为三个可感知、可描述、可学习的标签
2. **人设信号分析**：识别塑造人设的具体信号
3. **人设问题诊断**：发现人设塑造的问题
4. **合规边界分析**：按投顾口径分析每句话的风险类型、风险定级
5. **横向对比分析**：与参考主播对比各维度

**输出格式：**
- 风格三标签（标签名|具体行为描述|举例）
- 人设信号表（人设信号|原文示例|效果）
- 人设问题表（问题|原文示例|为什么有问题）
- 合规分析表（原表达|风险类型|风险定级|说明）
- 主播对比表（维度|本场主播|参考主播A|参考主播B）

---

### 第六层：迁移层 · 模板提取

**分析方法：**
1. **准备清单提取**：从个案中提取直播前的准备事项
2. **结构SOP提取**：提取直播各阶段的时长、任务、话术模板
3. **关键原则提取**：提炼可复用的核心原则
4. **改进建议输出**：给出具体的、可执行的改进方案

**输出格式：**
- 直播前准备清单（5项以上）
- 直播结构SOP表（阶段|时长|任务|话术模板）
- 关键原则（5条以上）
- 我可以直接复用的3件事
- 改进建议（按优先级排序，每条包含：问题|建议改法|示例|为什么有效）

## 六、使用指南

### 分析流程建议

```
Step 1 准备材料：直播逐字稿/视频内容摘要
Step 2 快速诊断：使用简化版模板输出初步发现
Step 3 深度分析：使用完整版模板逐层拆解
Step 4 专项分析：根据需要使用话术/合规/对比专项模板
Step 5 输出报告：按HTML模板格式输出完整报告
```

### 分析时间建议

| 分析类型 | 建议时间 | 适用场景 |
|---------|---------|---------|
| 快速诊断 | 15-30分钟 | 初步了解、快速反馈 |
| 完整分析 | 60-90分钟 | 深度诊断、竞品分析 |
| 专项分析 | 30-45分钟 | 特定问题深入 |
| 对比分析 | 45-60分钟 | 多主播横向对比 |

### 注意事项

1. **先看结构，再看内容**：结构决定直播效果的基础
2. **话术按功能分类**：不要只摘录，要分析"为什么这么说"
3. **合规是财经直播的生命线**：必须检查每句话的风险
4. **输出要可执行**：不只是描述问题，要给出改进方案
5. **模板化发现最有价值**：发现博主使用统一模板，揭示高效输出的真相
